# 安全与隐私报告 / Security and privacy reports

Do not include API keys, tokens, institutional credentials, private papers, personal financial records or unpublished research data in public issues, pull requests or logs.

For a vulnerability or unintended disclosure, use GitHub private vulnerability reporting if it is enabled for this repository. If no private channel is available, open a public issue containing only a request for a private contact route, without exploit details or sensitive data. No response-time or security-audit guarantee is offered.

For ordinary bugs, provide the commit, command, platform, exit code and a minimal synthetic reproduction. The installer does not configure accounts or overwrite existing entries. Review skills and scripts before granting them tool access.

Known-pattern credential scanning is a maintenance check, not comprehensive secret detection or a security certification. Model behavior and external services require their own authorization and verification.
