# 迭代路线

目标是让研究者能理解、安装、配置并复用 Research Agent，同时保持证据可追溯和作者决策权。路线按实际用户问题推进，不以技能数量、代理数量或外部项目复杂度作为质量目标。

## 本轮分发改进

- 以 skills/catalog.json 明确启用技能、共享资源、停用参考和分发排除项。
- 提供显式安装、安装计划、完整性检查与安全暂存，保留已有安装。
- 用可选知识库绑定替代个人路径前提，明确无私有库时的使用方式。
- 提供中英文入口、可复用输入示例、贡献与问题报告流程。
- 保留组件许可，并将未确认许可的参考素材移出当前跟踪范围。
- 配置跨平台离线 CI；实际支持范围以每个提交的运行记录为准。

这些是交付范围，不表示已经取得跨平台运行结果或科研效果提升。

## 需要持续核验的事项

| 事项 | 下一步验收依据 |
|---|---|
| 跨平台分发 | 对应提交在 Windows、Linux、macOS 的 CI 与安装检查结果 |
| 新用户首次使用 | 在自己的项目发现技能，完成至少一项有原始材料的真实任务 |
| 文档与文件生成 | 用户所选工具的实际渲染、可编辑性和内容检查 |
| 本地知识库接入 | 自己的后端、来源、索引和原文定位经实际查询验证 |
| 科研效果 | 正常研究任务中检查证据支撑、事实保留与作者修改负担 |

## 按真实需求开展

plugin 分发、更多宿主适配、安装更新辅助和可共享知识库后端，只有出现明确用户需求及维护能力时再做。每项先定义具体失败场景与验收，不默认引入第二套运行时、自动自我改写或通用科研评分器。

论文代码复现、专业实验执行和机构访问仍需对应工具、环境与授权。用户决定科学方向；已有问题、数据、结果和手稿可以直接从相应任务开始。
