# 从文献证据到可写的论证

目标是使每一步解释都能回答“这些证据为什么支持这句话”，同时保留阅读正文的流畅性。证据表是工作材料，不应取代正文。

## 从作者问题检索

先把当前段落要解决的未知拆成可检验的小问题，再构造检索。复用现有 nature-literature-kb，必要时补充最新原始研究。检索成功只表示找到候选材料。未返回的文章不能据此判定不存在；没有命中也不证明领域空白。

对引言的中心缺口，至少考虑最接近的已有工作和可能推翻缺口说法的研究。无须机械规定引用数量。应以论证覆盖为准，分清奠基研究、最近工作、对立证据和适用边界。只按期刊品牌过滤会偏离问题本身，除非作者明确限定文献范围。

## 保存最小支持单位

优先复用既有文献卡片或证据账本。只有新证据或主张变化时才增补记录。每项记录含原始来源、稳定定位、相关发现、研究设计、对象与尺度、比较条件、局限、它支持的具体句意以及它不支持的外推。能定位到页码、表、图或小节时不要只保存摘要。

仅有摘要时，不能写入摘要没有说明的方法或结果细节。可按摘要层级使用明确报告的发现，并说明覆盖范围。DOI 存在、题名匹配和引用格式正确都不能证明语义支持。不得伪造全文阅读、人工核实或专家一致意见。

## 综合需要一个明确的推理桥梁

多篇研究来自相同背景并不自动构成一条共同结论。准备综合句时，依次检查对象是否可比，测量指标是否同义，时间与空间尺度是否一致，比较基准是否相容，研究设计能否支持所用因果词。不同尺度或不同测量的发现可以形成“现有证据在何种条件下分化”的论点，无须硬拼成统一规律。

将草拟主张分为三类。直接发现应由相应研究或本项目结果支持。跨文献解释应指出综合依据及适用边界。尚未验证的机制只能作为解释候选或待检验命题。反向证据会改变主张范围，不能被放进参考列表后忽略。

检验桥梁的一种办法是尝试构造反例：即使所有引用文献的结论都为真，这个综合句是否仍可能为假？若可能，找到缺失前提，收缩结论或补充针对性证据。不要把模型对领域的熟悉感当作这个前提的来源。

## 引言段落的推进

每段解决一个实质问题：已有何种认识，最相关研究推进到哪里，这些认识在什么条件下仍不足，缺口对理解或决策有何后果，本研究的设计能够回答其中哪一部分。让下一段的问题来自上一段留下的具体限制。删除“研究很少”“方法尚不完善”之类无法核查且无法解释后果的宽泛句。

正式写作要把证据、解释和推进关系融为完整自然段。不要将内部字段名、证据编号、版本号、查询词或推理草表写进正文。引用保留读者需要的标准格式，内部证据定位保留在伴随材料。

## 证据不足的局部处理

缺关键论证证据时，优先删除过强限定、明确范围或保留可确认的较窄主张。缺少决定研究贡献的关键证据时，向作者说明可支持的结论与额外研究需求。不得为保证“故事完整”捏造新结果，也不得把整个已授权写作任务退化成寻找更多文献。
