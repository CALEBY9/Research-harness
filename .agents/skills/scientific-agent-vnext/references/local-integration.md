## 实际加载

使用选定项目绑定中的绝对路径；不要在其他项目中自动寻找本机绑定。维护项目绑定只提供方法与工具定位，不替代目标科研项目的最新 AGENTS、状态、正文、设计和证据。没有真实稿件路径时，不声称已选定写作输入。

| 请求 | 按需读取 `upstream_method_routes` |
|---|---|
| 论文新写、实质重构、文献综合 | `manuscript_core` 中各文件的完整方法内容 |
| 引言或标题 | 加 `introduction` |
| Discussion、综述、整稿组织 | 加 `structure`，选符合研究类型的部分 |
| 摘要 | 加 `abstract`，使用真实已完成结果 |
| 实质修订 | 加 `revision` |
| 正文完成后的检查 | 加 `review` |
| 作者明确提供可用文风样本 | 加 `style_calibration`；样本不是事实证据 |
| 引用格式调整 | 按需 `citations`，以真实模板和期刊要求为准 |

只做语言编辑或日常模板文档时，直接使用 `project-writing.md`；不加载整套 ARS。日常文档中的文献综合段落可以单独使用相关方法。绑定文件缺失时报告依赖问题，不静默换写作配置。不得仅凭路由表声称方法已实际读取。

## 与完整上游的明确差异

保留中心问题、证据与推理联系、反论证、段落组织、章节推进、最近工作比较、证据限制及修订诊断的完整方法文本。上游文件中的固定段数、子论点数、引用密度、字数比例、自评分和示例句式只作教学示例；实际篇幅、语言、文类、学校和期刊要求由当前任务确定。简体中文为沟通默认值。不要将教育或算法案例套成环境地理研究设计。

上游对调度器、其他代理、PCR、Material Passport、阶段目录、先承诺再打分、finalizer、自动重试及更新的要求不在本候选运行范围。由同一负责人从已有材料恢复所需问题、证据和限制；不让作者补交重复表单，也不宣称已运行这些机制。结构、引用和双语格式参考中的库文件与模板按实际需求另行核验，不递归加载完整套件。

修订按用户授权进行最小必要编辑，并在独立候选目录交付完整请求范围内的正文。现有项目若已经采用正式补丁授权、受保护图件、冻结设计或逐项审批，继续遵守；本适配不能作为绕过依据。未采用完整上游 patch 1.1 系统的项目不新建这一系统，也不声称其机械保障已生效。

引用必须保留可回查的支持位置与版本。复用已有证据账本，必要时放在简短独立说明；不自动在成品插入上游 HTML 标记、claim manifest 或内部日志。缺少 finalizer 不减轻原文支持核对义务。PDF 提取若有截断或页码异常，应重查可见原文；未经核验的页码不能冒充已验证定位。

材料缺口不得靠标题、摘要标签或模型常识推测论文结果，更不得补写未实施的方法、统计、验证和人工审阅。上游示例及其性能声明不作为用户论文证据。作者问题与当前证据不足以支持某句时，报告具体缺口或提出有依据的纠正；涉及科学承诺变化，沿用作者决定。新颖性须有真实检索范围与最近工作支持，作者偏好也不能使未经核实的“首次”成为事实。

保留主张强度、分母、比较基准、条件、否定结果、时间与版本一致性。因果动词加上“可能”不能将关联证据变成因果证据。科学边界优先于文风和压缩；已有明确受保护措辞照原要求保留。学科与期刊风格的泛化说法须用实际规范或同类论文核查，不能仅因参考文件这样写就当作硬规则。

这些适配只确定可审查的运行约定。技能结构检查、文件存在和数字比较都不证明模型遵循、知识库连通或写作质量提高。
