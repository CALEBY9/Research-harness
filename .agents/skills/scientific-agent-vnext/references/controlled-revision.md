# 受控修订

修订目标是改善作者可用性，同时守住研究含义。原稿可能有错；保留科学含义不要求保留已证实的错误。

## 根据变更性质处理

语言层面的修改可以直接完成：语法、冗余、术语一致、句间联系和不改变句意的表达。无需启动新文献检索或全稿重构。

论证层面的修改包括调整段落顺序、补全已有证据的解释、区分发现与推测、修复跨段冲突。限定在作者授权的范围内，核对所依赖的证据和相邻段落，避免局部提高流畅度却削弱全稿主线。

科学层面的修改包括研究问题、统计单位、分析集合、权重、主要比较、指标定义、因果强度、验证身份或核心贡献改变。先提出独立的修改建议，解释证据和影响；未经作者确认不写入正式稿。新分析保持独立分支，与原稿图表版本不能混合。

## 对照的科学含义

对实质修订，逐项检查修改前后是否改变研究对象与样本范围、时空尺度、分母与计数口径、变量或指标单位、比较基准、估计方向与大小、不确定性、相关或因果表述、情景或观测性质、人工或模型验证身份。

这些检查依据原稿、结果文件和研究协议。数字没变也可能发生严重漂移，例如“在给定情景下可能减少排放”被改为“将减少排放”。数字变化也可能只是正确纠错，因此机械比较只能提供待查看位置。

保留作者已经认可的有效内容。批评某一段落不授权无差别重写全文。引用编号、语态、标题和术语的必要连带修复可在授权范围内完成；超出范围的主线重构单独提出。

## 避免局部修复造成整稿矛盾

修改结论后回看相应摘要与讨论。修改概念定义后搜索该概念的其他使用位置。修改结果的表达后确认图注、表注、方法中的同一口径。不能读到相关当前文件时，说明尚未完成整稿一致性核查。

相互冲突的稿件与历史状态不能靠选择更新日期解决。检查实际权威记录。哈希不匹配意味着内容身份不同，不能据此直接推定损坏，也不能沿用历史验收。

## 简短记录

正常交付保留“修改了什么、保持了什么、哪些事项尚未核实”。高风险项目沿用已有受保护文件、授权和交接规定。无需给所有写作任务新增完整审计体系。

最终稿不保留内部检查字段。未证实的内容不通过删除提示标记变为已证实。为了交付看起来干净而隐藏待核查问题属于失败。
