# 日常项目与文档写作

从作者要求的文类、收件人、用途、篇幅和可用材料开始。明确材料充分时直接交付正文。论文写作、博士开题、读书报告和进展汇报可共用证据原则，但不必共用结构。

## 只改表达

对粘贴段落或指定局部，保持数字、引用、专业术语和主张强度。不要重建整个知识库、重置项目状态或插入新文献。原句存在明确科学歧义时局部说明，避免把普通语言润色扩展为科研审查。

## 开题报告与研究计划

优先执行学校、项目或导师的真实模板。文献现状应服务于问题提出，研究目标与研究内容应能对应到方法、数据和可行性。清楚区分已获得的基础、拟开展的研究、预期结果与无法保证的产出。不能将预期创新写成已经发现的新机制。

材料不足的行政字段使用明确占位提示，并放在说明中。缺少决定研究可行性的关键信息时提出具体风险，不杜撰已有数据、伦理审批或项目支持。

## 文献综述与读书报告

按照当前主题与文类建立比较轴。学术综述可比较理论、方法、证据与适用范围；文学读书报告需要文本细读、作品结构与具体论证。不能只增加案例和参考文献来掩盖题文不一致。新增案例要说明它改变或支持当前论点的具体位置。

文本引用应有可核查作品版本与页码，资料不足时不要编造对白或情节。统计多少篇文献或几类案例，必须明确纳入范围、分类是否互斥及分母；无法确认的数量不得写成确定统计结果。

## 项目汇报与常规说明

进展报告区分已经完成、正在进行、尚未开展和待决事项。研究困难要说明对结果或进度的实际影响。普通工作邮件与项目说明采用直接表达，无需引入“重大科学意义”或“填补空白”。

## 格式交付

优先复用已经可靠的 DOCX、LaTeX、PPT 或图件工具。内容确认与页面渲染分开验证。若当前运行时具备文档或幻灯片技能，读取其规定并生成、渲染检查实际文件。检查标题层级、分页、表格溢出、字体替换、图片质量、参考文献与交叉引用。

无法生成或渲染某种格式时，交付已经完成的正文或可编辑源文件，并明确格式核查尚未执行。不要仅凭文件存在宣称版面合格。不能把这份技能参考当作已经安装 Office 或渲染服务。
