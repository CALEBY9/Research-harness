# 学科适配与操作示例

以下均为方法演示，不代表已经核验的项目结果，也不能直接作为论文中的事实或引用。

## 环境科学、地理学和能源生态研究

空间相邻样本可能共享背景条件。描述空间集聚时，不能自动推导空间因果机制。某项模型的解释变量重要性、特征归因或相关性也不直接等于因果贡献。实际使用什么识别策略，决定可以采用什么强度的结论。

情景模拟的结果依赖输入假设、模型边界和比较基准。把情景输出改成无条件未来预测会改变科学含义。生态系统服务的潜在供给、实际流量、人类使用与福祉收益需要按研究定义分别讨论。装机位置和发电效率的证据未必足以证明净减排或生态净收益。

系统综述、范围综述与科学计量图谱可能具有不同的纳入目标。文献内的分类分布不能直接外推整个研究领域；文章篇数增加不自动证明采用比例上升。样本代表性、分层权重、重复编码、人工与模型判断身份应以本项目实际协议为准。

## DL-GEE 类型任务的跨文献综合演示

设文献甲报告某任务中加入过程知识后预测表现改善，文献乙整理过程知识参与方式，文献丙统计相关论文增长。三者共同为真时，“过程知识普遍提高地学模型泛化能力”仍可能不成立，因为任务、评价条件、比较基准和泛化定义尚未对齐。

可检验的较窄问题是：现有文献中的过程知识融合实践如何分布在不同任务及参与位置，现有评价是否足以支持跨情景的一般性判断。该问题仍必须由作者实际纳入范围、分类设计和结果支持，不能直接替换作者原有主线。

写作演示：有关研究从性能改进、方法分类和应用扩展等角度描述了过程知识与数据驱动模型的结合。但这些证据回答的问题并不相同。某一任务中的效果比较能够支持局部性能判断，分类与数量统计则刻画实践的组织和扩展。把这些证据放在同一分析框架中，需要保留任务与评价条件的差异，才能区分实践分布与效果证据。

上段没有具体引文，属于表达示范，不能直接放进正式稿。真实写作需要绑定实际文献并针对作者设计收缩或改变范围。

## 风电 Discussion 类型任务的修订演示

原句：“在给定布局与替代基准下，情景模拟表明该方案可能具有较高减排潜力。”

危险改法：“该方案将带来更高减排收益。”

问题在于删掉情景、比较基准和不确定性，并把潜力转成实际收益。即使没有改变任何数字，推断身份仍已变化。改进表达应保留这些关键条件，再解释布局差异通过何种被实际分析的因素影响结果。

## AI 方法研究

当研究确实提出算法并运行了可比实验时，任务定义、基线、消融和泛化评估可以成为组织核心。若研究对象是已有文献中的方法实践，不能把这种工程创新框架强加给综述。复用 ML 写作技能时先确认文章类型，随后仅使用有助于当前任务的段落逻辑。

## 人文学术与读书报告

人文论证可通过概念辨析、文本证据、情节结构和竞争性解释推进。不要伪装为自然科学的因果验证流程。新引入的人物、情节与引语必须可在指定作品或可靠研究中找到。单纯添加案例数量，无法保证标题所承诺的问题已经回答。
