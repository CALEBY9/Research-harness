# 问题收敛与选题

依据 ARS Research Question、Socratic Mentor 与研究架构方法进行本地适配；
来源见 [provenance.md](provenance.md)。本分支只完成本次问题收敛，不代替
作者选择研究方向，也不启动实验或正文写作。

## 从模糊题材到可回答的问题

先复用用户材料和项目既有决定，识别研究对象、现象或矛盾、空间/时间尺度、
观测单位、目标变量以及能得到的证据。若用户已有明确问题，不把它重新
拆成一轮选题；当前请求只是搭框架时使用框架模式。

将题材分为可检验的问题类型，避免所有任务都写成因果机制：

| 问题类型 | 需要说明的可区分答案 | 典型证据要求 |
|---|---|---|
| 描述 | 什么分布、状态或差异尚未被可靠刻画 | 定义一致的观测、覆盖与测量限制 |
| 比较 | 哪些条件下两类对象或方法出现何种差异 | 可比较样本、尺度、基线和指标 |
| 关联 | 哪些变量或过程共同变化 | 测量有效性、混杂与选择偏差 |
| 解释/因果 | 哪个解释能被排除，何种观测区分竞争解释 | 识别策略、对照、时间顺序或可信机制证据 |
| 资源/综合 | 统一哪些原来不可比较的信息，支持什么新判断 | 来源、操作定义、可追溯编码与覆盖边界 |

## FINER：逐项给理由

保留 ARS 的 FINER 结构，按实际证据定性判断，不将未经校准的总分变成
新颖性或可发表性结论。

- **Feasible**：数据是否存在、可获取、变量含义是否匹配；已获得与仅计划
  获取的资源分别说明。不能从文件名推定变量、单位或可用范围。
- **Interesting**：答案会改变哪项科学认识；若预期答案成立或不成立，
  各自告诉研究者什么。实际困惑优先于“尚无人组合这些关键词”。
- **Novel**：查最近先行工作，比较对象、尺度、数据、方法和核心主张。
  未检索充分时仅提出待核实的差异，不能写“首次”。
- **Ethical**：识别与该候选实际有关的研究伦理、数据许可和隐私约束。
  不替代机构伦理审批，也不为无关任务增加审批流程。
- **Relevant**：说明结果对该领域的理论、证据或实践判断有何作用。

## 生成与比较候选

只有任务要求候选问题时才生成一组与证据充分程度相称的候选，不规定数量。
每个候选至少交代以下内容，可在同一张表中表达：

1. 精确问题、研究对象、观测单位和范围。
2. 有来源的科学动机、最近先行工作与剩余差异。
3. 假设及区分竞争解释的观测；描述性候选写其新增知识。
4. 已可用/待获取的数据、关键变量含义、主要可行性限制。
5. 最小检验或比较思路，以及什么结果会否定原主张或新颖性判断。
6. FINER 的实质理由、主要风险与建议；证据不足时保留未知。

排序时比较科学问题的重要性、差异的可辩护性、数据现实、方法可执行性
与风险，不把同一现象换地区、换模型或扩大关键词范围自动视为创新。
环境科学候选需要时可复用
[科学判断标准](../../nature-scientific-insight/references/judgment-criteria.md)，
只读相关部分，不另起一轮独立判断。单独评价一个已给定想法时转
`nature-scientific-insight`。

## Socratic 引导分支

用户明确希望通过提问自己想清楚时使用。一次聚焦当前最关键的未定问题，
不先要求填完量表，也不以固定轮次阻塞已有充分信息的工作。
保留 ARS 六类提问：

| 类型 | 可按当前材料选择的问题 |
|---|---|
| 澄清概念 | “这里的 X 指什么？包含什么，不包含什么？” |
| 检查假设 | “这个推理默认了什么？该前提不成立会怎样？” |
| 追问证据 | “什么观测支持或反驳它？证据怎样区分两种解释？” |
| 改变视角 | “另一种理论或另一类对象会怎样解释同一现象？” |
| 检查含义 | “答案会改变什么判断？哪些对象或条件下不适用？” |
| 反思问题 | “真正想回答的问题是什么？现在的问法能够回答吗？” |

只总结用户已经表达的认识，不将系统生成的候选归为作者自己推导的洞察。
未收敛时指出具体未定点并继续聚焦提问；用户改为要求直接给候选时，明确
说明切换为系统建议，再按前述候选流程执行。不要以长期追问代替用户要求
的调研或候选产物。

## 完成条件

交付当前问题简报、必要的候选比较及来源与未知项。子问题继承主要问题
的对象、时间、地域和尺度；拟改变已确认边界的科学取舍交给作者。
未被选定的候选仍是候选，不能静默进入具体实验或论文写作。
