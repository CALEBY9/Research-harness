# 科研洞察与判断

这是 Research Agent 的核心科学判断技能。帮助研究者判断一个问题是否值得研究、
方法改变了什么推断能力、现有证据支持什么认识，以及下一步最值得投入哪里。
给出有根据的建议；研究方向、核心主张及实质科学取舍由研究者决定。

显式入口为 `$nature-scientific-insight`，也可说“调用 Research agent，判断……”。
当任务的主要交付物是科学判断、路线取舍或贡献比较时，本技能是主要 owner。
发现候选、设计方法、解释结果和写作技能按需要复用这里的判断标准，避免重复裁决。
已确认问题的普通执行、语言润色、排版和资料获取直接使用对应技能。

## 识别当前工作单元

“这个现象值得研究吗”“与最近研究相比新在哪里”“这个机制可信吗”“已有结果
能改变什么认识”“该保留哪条主线”“下一步做什么最能改变判断”，都属于本技能。
“Is this idea novel and publishable?”先判断实际贡献与证据，再按请求讨论发表定位。
它可以出现在选题、设计或结果阶段，不要求先跑完整文献阅读流程。

只要领域图谱或一批新假设，用 `nature-research-discovery`；已确认问题的实施方法或完整验证计划，
用 `nature-method-design` 或 `nature-experiment-plan`；完整稿件的正式模拟审稿，用 `nature-reviewer`。
同一任务可能借助这些能力，但以研究选择为交付物时由本技能负责结论。
“洞察”不是额外创意数量、文献摘要或泛泛的专家意见。

## 从当前决策开始

先明确研究者正在决定什么：选题、创新性、方法价值、解释选择、主张强度、
论文定位或继续投入。只处理当前选择，不把一次判断扩展成完整研究流水线。
读取 [judgment-criteria.md](references/judgment-criteria.md)，按当前问题使用有关维度。

恢复作者确认的研究对象、空间和时间尺度、独立样本单位、测量定义、分母、
比较对象、数据现实与受保护产物。复用现有证据及已成立的判断，找出哪个新信息
可能改变结论。不要因为缺少某个旧工作流文件而把已有研究判为不合格。

## 建立可核查的判断

1. **说清新增认识。** 写出已有研究已经允许得出的结论，以及本研究增加的
   估计、解释、边界、可比较证据或资源。把科学重要性与技术便利分开。
2. **寻找最强反证。** 从最接近的原始研究与最可信的竞争解释出发，核查对象、
   方法、数据和结论的重合，指出还能成立的贡献。检索覆盖不足时保留未知。
3. **比较证据与主张。** 区分观测、解释、预测、情景结果和因果主张；说明决定性
   证据在哪里、哪项假设尚未检验、什么结果会改变建议。因研究类型而异，
   描述研究不必编造机制，方法研究不必虚构额外生态发现。
4. **比较可选行动。** 解释现有证据为何支持继续、收窄、重构、补证据、暂缓或
   放弃某个具体主张。给出最小的区分性检验或缺失来源，明确新增投入能解决什么。
   推荐下一步是在选择最有信息价值的行动；完整实验方案由对应 owner 承担。

对核心判断使用原文页、章节、表图、数据字段或分析产物定位。文献卡片与知识库
检索只提供候选证据。不同技能或模型的意见按其证据比较；来源身份、模型分数、
脚本成功及精美图件都不能替代科学支持。不要编造“首次”、创新分数、接收概率或
已有人类专家认可的记录。

## 使用支持能力

| 具体缺口 | 按需使用 |
|---|---|
| 原始文献、最近先行研究或检索覆盖不足 | `nature-academic-search`；本地已注册语料用 `nature-literature-kb`；关键单篇用 `nature-reader` 的 paper-card 模式 |
| 需要发现新候选问题或建立领域图谱 | `nature-research-discovery` |
| 需要形成可实施方法或实验计划 | `nature-method-design` 或 `nature-experiment-plan` |
| 结果尚未计算或尚未整理解释 | `nature-data-analysis`，按需选择计算或已完成结果解释模式 |
| 数据、数字、代码或来源的可靠性存在具体疑问 | `nature-evidence-audit`；完整模拟审稿报告用 `nature-reviewer` |
| 已获作者认可的判断需要转为正文或图件 | `nature-writing` 或 `nature-figure` |
| 已有公开学者判断框架与当前问题相关 | 使用 `nature-scholar-distiller` 的有来源产物，回到原文核查适用性 |

从实际安装目录和可用工具解析支持技能；不假定 Nature 与本地技能位于同一根目录。
支持能力是具体证据缺口的工具，不是所有判断的必经步骤。复用有效证据时不重复
检索或计算；新的实验、模型调用、受保护产物变更按当前任务授权处理。

## 交付给研究者

先给判断与关键理由，再给足以复核的证据、假设、最强异议和会改变判断的条件。
比较多个选项时可以用一张表。对证据充分、仅有间接支持、未知和受到反证的部分
作清楚区分，不用评分掩盖权衡，也不把所有结论弱化成“可能”。

即使某个核心主张不成立，也应说明仍有价值的结果和更窄的贡献。证据缺失与
已有证据否定是两种不同状态；未知不能编码为零效应或失败。负结果在研究能
区分假设、排除有意义效应或识别边界时可能有科学价值。

建议改变作者已确认的问题、样本、估计对象、核心主张或因果强度时，说明理由、
代价及选项，交给作者决定。给出建议不自动授权后续独立研究阶段。
默认在对话或项目已有的证据说明中交付；按请求保存文件，不新建平行状态库。
